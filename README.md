# 西语闪卡 esp_flashcard

571 课西语词汇 / 短语 / 句型闪卡（约 11,000 张，带配图）的安卓 app。

- 切换卡片自动用系统 TTS 朗读西语（需要手机装有西班牙语语音）
- 点击卡片 3D 翻转，左右滑动切换，带飞出 / 滑入动画
- 配图在英文释义一面
- 每 5 课一个单元，按课号顺序排列
- 单词本：☆ 加入，按 SM-2 间隔复习（忘了 / 模糊 / 记得 / 简单），复习间隔达到"掌握标准"（默认 60 天）且答对就自动移出

推送到 main 后 GitHub Actions 自动编译，APK 在 Releases 页面下载。

目录：`web/` 是整个界面（index.html）、词库 cards.json 和配图 img/，原样打包进 APK 的 assets；`app/` 是 WebView 外壳和朗读桥接。
签名文件 `signing/release.jks` 是本应用专用的，放在仓库里是为了每次云端编译签名一致、可以覆盖升级。
